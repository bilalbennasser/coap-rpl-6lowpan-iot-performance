# Legacy analysis

`analyse_tp08_initial.py` is the preliminary TP08 analysis covering Q1 and Q2 only (12 simulations).

It is preserved for historical and methodological context.
It also reports duplicate RX observations and timeouts.

The authoritative analysis covering Q1, Q2, and Q3 is `../tp08_final.py`.

The legacy script requires `--logs-dir` and `--output-dir`. Original logs are not included in this repository.
